## Роль в курсе

Хранение истории проектов курса и загрузка pico-sdk: SDK распространяется как Git-репозиторий и клонируется вместе с подмодулями. Контроль версий обеспечивает воспроизводимость: по истории изменений известно, какой версией кода получены данные эксперимента.

## Установка

Подойдёт любая версия. Проверка — `git --version`.

### Windows

Скачайте установщик с https://git-scm.com/downloads и запустите его. Все настройки оставьте по умолчанию: галочка добавления в `PATH` в них уже включена.

### macOS

``` bash
brew install git
```

### Linux

``` bash
sudo apt update
sudo apt install git
```

## После установки

Представьтесь Git — эти данные попадут в каждый ваш коммит:

``` bash
git config --global user.name "Имя Фамилия"
git config --global user.email "почта@example.com"
```
