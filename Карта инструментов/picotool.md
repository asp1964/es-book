>[!note] Описание
>**picotool** — утилита Raspberry Pi для работы с прошивками RP2040: показывает содержимое файлов прошивки, преобразует форматы и записывает прошивку в плату, подключённую в режиме загрузчика.
^def

## Роль в курсе

Инструмент осмотра и записи прошивки. Сборка проекта опирается на picotool при генерации дополнительных форматов вывода, поэтому утилита должна быть установлена ещё до первой сборки. Команда `picotool info` показывает, что за прошивка лежит в плате, — это способ убедиться, что записано именно то, что собрано.

## Установка

>[!warning] Версия обязана совпасть с версией SDK
>picotool — единственный инструмент курса, версию которого нельзя выбирать свободно: она должна совпадать с версией [[pico-sdk#^def|pico-sdk]]. Курс работает на `2.3.0`. При несовпадении конфигурация сборки прерывается сообщением `Incompatible picotool installation found`.

### macOS

Проще всего через [[Homebrew#^def|Homebrew]] — он скачает, распакует и пропишет путь сам:

``` bash
brew install picotool
```

### Windows, Linux и запасной путь для macOS

Готовые сборки для всех трёх систем лежат на странице релизов `pico-sdk-tools`: https://github.com/raspberrypi/pico-sdk-tools/releases. Список файлов там длинный, разверните его целиком и найдите архив своей системы в релизе `v2.3.0-0`:

- Windows — `picotool-2.3.0-x64-win.zip`
- macOS — `picotool-2.3.0-mac.zip`
- Linux — `picotool-2.3.0-x86_64-lin.tar.gz`, на компьютерах с процессором ARM `picotool-2.3.0-aarch64-lin.tar.gz`

Порядок одинаков везде: распаковать архив, положить папку в постоянное место (в Windows — например, `C:\Program Files\picotool`), добавить путь к исполняемому файлу в `PATH` ([[Настройка переменных среды#^def|Настройка переменных среды]]), перезапустить терминал. Установщика у picotool нет — запускать из архива ничего не нужно.

### Проверка

``` bash
picotool version
```

В ответе — версия утилиты, система и компилятор, которым она собрана:

```
picotool v2.3.0 (Darwin, AppleClang-21.0.0.21000099, Release)
```

Значение имеет только `v2.3.0`; остальное зависит от того, как собрана именно ваша сборка.

>[!warning] Сверьте версию, которую даёт пакетный менеджер
>Сопровождающие Homebrew и репозиториев Linux обновляют пакеты своим ритмом и могут отставать от Raspberry Pi: в феврале 2026 года `brew install picotool` ставил `2.2.0`, несовместимую с SDK `2.3.0`. Поэтому проверка версии здесь не формальность. Если менеджер отстал — берите архив со страницы релизов.

Если готовой сборки для вашей системы не нашлось, picotool собирается из исходников по инструкции репозитория — для этого уже должны стоять CMake, компилятор и pico-sdk.
