>[!note] Описание
>**GNU Make** — исполнитель сценариев сборки: читает файл `Makefile` с правилами «цель — зависимости — команды» и вызывает нужные программы, пропуская то, что пересобирать не требуется.
^def

## Роль в курсе

Второй шаг сборки каждого проекта. CMake генерирует `Makefile` по описанию проекта, Make по этому файлу запускает компилятор и компоновщик и получает прошивку. Команда `make` в директории `build` — то, чем в курсе собирается любой проект.

## Установка

Подойдёт любая версия. Проверка — `make --version`.

### Windows

Установщика с добавлением в `PATH` у GNU Make нет, поэтому путь придётся прописать руками.

1. Скачайте установщик с https://gnuwin32.sourceforge.net/packages/make.htm — ссылка **Setup** в строке «Complete package, except sources».

![[Страница загрузки Make.png|500]]

Загрузка начнётся не сразу: сначала откроется страница SourceForge, файл `make-3.81.exe` скачается с неё через несколько секунд.

![[Начало загрузки Make на SourceForge.png|500]]

2. Запустите его и пройдите шаги установки.

![[Мастер установки Make.png|400]]

3. Найдите папку с `make.exe`; при установке по умолчанию это `C:\Program Files (x86)\GnuWin32\bin`.
4. Добавьте эту папку в `PATH` — как это сделать, описано в навыке [[Настройка переменных среды#^def|Настройка переменных среды]].
5. Перезапустите терминал.

### macOS

Make входит в Command Line Tools для Xcode и обычно уже установлен. Если команда не находится:

``` bash
xcode-select --install
```

### Linux

``` bash
sudo apt update
sudo apt install make
```
