>[!note] Описание
>**Homebrew** (в командной строке — `brew`) — сторонний менеджер пакетов для macOS: устанавливает программы одной командой, сам разрешает зависимости и прописывает пути к исполняемым файлам.
^def

## Роль в курсе

Штатный способ поставить инструменты курса на macOS: `git`, `cmake`, `make`, компилятор `arm-none-eabi-gcc`. В Windows и Linux не используется — там свои способы установки.

Если `brew install` не находит пакет или ставит версию старее ожидаемой, начинайте разбор с обновления локального списка пакетов — навык [[Обновление списка пакетов#^def|Обновление списка пакетов]].

## Установка

Требуются Command Line Tools для Xcode; если их нет, система предложит поставить сама.

``` bash
xcode-select --install
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

После установки закройте терминал и откройте заново, затем проверьте:

``` bash
brew --version
```
