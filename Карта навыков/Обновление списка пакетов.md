>[!NOTE] Навык
>**Обновление списка пакетов** — умение обновить локальный список доступных пакетов перед установкой программы и понимание того, что менеджер пакетов работает не с самим репозиторием, а с его копией на вашем компьютере.
^def

## Что нужно знать

[[Менеджер пакетов#^def|Менеджер пакетов]] хранит на компьютере локальный индекс: какие пакеты существуют, каких они версий, что от чего зависит. Установка идёт по этому индексу, а не по свежим данным с сервера. Пока индекс не обновлён, система «не знает» о новых пакетах и версиях.

Отсюда три типичных сбоя при установке без обновления индекса: пакет не находится, ставится устаревшая версия, установка обрывается на несовместимых зависимостях.

## Linux

Команда обновляет индекс из репозиториев, перечисленных в настройках системы; сами программы она не трогает:

``` bash
sudo apt update
```

Выполняйте её перед установкой (`apt install`) и обновлением (`apt upgrade`) пакетов. Обычная связка команд выглядит так:

``` bash
sudo apt update          # обновляем список пакетов
sudo apt upgrade         # устанавливаем обновления
```

## macOS

У [[Homebrew#^def|Homebrew]] та же логика: `brew` хранит локальную копию описаний пакетов и обновляет её командой

``` bash
brew update
```

Свежие версии Homebrew обновляют индекс сами при установке, поэтому команда нужна не всегда. Но если `brew install` не находит пакет или ставит версию старее ожидаемой — начинайте разбор именно с неё.

## Windows

Штатного менеджера пакетов в курсе не используем: программы ставятся установщиками с сайтов, обновлять нечего.
