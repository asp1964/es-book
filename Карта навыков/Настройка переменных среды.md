>[!NOTE] Навык
>**Настройка переменных среды** — умение создать или изменить переменную среды ОС (`PATH`, `PICO_SDK_PATH`) и проверить её значение из терминала; понимание того, что новое значение видно только в терминалах, запущенных после изменения.
^def

## Что нужно знать

[[Переменная среды#^def|Переменные среды]] можно изменить временно — на текущую сессию терминала — и постоянно. В курсе нужны постоянные: временное значение пропадёт вместе с окном терминала, и сборка перестанет находить SDK.

Две задачи различаются:

- **создать новую переменную** — так задаётся `PICO_SDK_PATH`, которой в системе раньше не было;
- **дописать значение в существующую** — так работают с `PATH`: эта переменная уже есть, и её нельзя перезаписывать, можно только добавлять к ней пути.

> [!ERROR] Обратите внимание
> Изменённое значение переменной среды применяется только после перезапуска терминала. Если после настройки команда по-прежнему не находится — первым делом закройте терминал и откройте заново.

## Создать переменную среды

### Windows

1. Откройте системный поиск и наберите `изменение системных переменных среды`. Выберите найденный вариант:

![[Поиск изменения системных переменных.png|400]]

2. В открывшемся окне `Свойства системы` нажмите снизу справа `Переменные среды`:

![[Окно Свойства системы.png|400]]

3. В окне `Переменные среды`, в нижней половине, в разделе `Системные переменные` нажмите `Создать`:

![[Создание системной переменной.png|400]]

4. В окне `Новая системная переменная` впишите имя переменной (например, `PICO_SDK_PATH`) и значение (например, `C:\Repositories\pico\pico-sdk\`). Путь должен содержать обратные слэши `\`:

![[Новая системная переменная.png|400]]

5. Нажмите `ОК` во всех открытых окнах. Готово.

### macOS

Постоянные переменные задаются в файле настроек оболочки. В macOS по умолчанию используется `zsh`, его файл — `~/.zshrc`.

1. Проверьте, какая у вас оболочка:

``` bash
echo $SHELL
```

2. Допишите строку в конец файла настроек:

``` bash
echo 'export PICO_SDK_PATH="$HOME/Repositories/pico/pico-sdk"' >> ~/.zshrc
```

3. Примените изменения к текущему терминалу:

``` bash
source ~/.zshrc
```

> [!INFO] Примечание
> Если `echo $SHELL` вывел `/bin/bash`, вместо `~/.zshrc` используйте `~/.bash_profile`.

### Linux

Порядок тот же, файл настроек оболочки — `~/.bashrc`:

``` bash
echo 'export PICO_SDK_PATH="$HOME/Repositories/pico/pico-sdk"' >> ~/.bashrc
source ~/.bashrc
```

## Добавить путь в PATH

`PATH` — переменная, в которой ОС ищет исполняемые файлы. Если программа установлена, но терминал отвечает «команда не найдена», значит путь к ней в `PATH` не попал.

### Windows

1. Откройте окно `Переменные среды`, как описано выше.

2. В разделе `Системные переменные` выберите переменную `Path` (может называться `Path` или `PATH`) и нажмите `Изменить`:

![[Выбор переменной Path.png|400]]

3. В окне `Изменить переменную среды` нажмите `Создать` — внизу появится пустая строка:

![[Новая строка в переменной Path.png|400]]

4. Впишите в неё путь к папке с исполняемым файлом. Путь должен содержать обратные слэши `\`:

![[Путь добавлен в переменную Path.jpg|400]]

5. Нажмите `ОК` во всех открытых окнах. Готово.

### macOS

Обычно добавление в `PATH` выполняет пакетный менеджер [[Homebrew#^def|brew]], и вручную ничего делать не нужно. Если всё же требуется:

``` bash
echo 'export PATH="$PATH:/путь/к/папке"' >> ~/.zshrc
source ~/.zshrc
```

Запись `$PATH:` в начале значения обязательна — она сохраняет уже имеющиеся пути. Без неё система перестанет находить большинство команд.

### Linux

``` bash
echo 'export PATH="$PATH:/путь/к/папке"' >> ~/.bashrc
source ~/.bashrc
```

## Проверить значение

Windows PowerShell:

``` powershell
$env:PICO_SDK_PATH
$env:PATH
```

macOS и Linux:

``` bash
echo $PICO_SDK_PATH
echo $PATH
```

Пустой вывод означает, что переменная не задана либо терминал был запущен до её создания.
